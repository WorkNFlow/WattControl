# ВаттКонтроль — Модуль детекции аномалий энергопотребления

Программный комплекс статистического анализа телеметрии умных счётчиков (Tuya IoT и совместимых) для малого бизнеса (кофейни, магазины у дома, автосервисы).

Сервис подключается к недорогому Wi-Fi счётчику на DIN-рейку, **7 дней без участия человека изучает нормальное поведение каждого канала** и выводит оперативное предупреждение на веб-дашборд при нештатном режиме (забытый на ночь прибор, сбой цикличности холодильника, перегрузка оборудования).

**Алгоритм — чистая математическая статистика (медиана, стандартное отклонение, анализ цикличности) без нейросетей.**

## Как запустить

Требуется только стандартный Python 3 (версия 3.8+). Никаких сторонних библиотек устанавливать не нужно.

### 1. Запуск сквозной демонстрации:
```bash
python3 run_demo.py
```
Скрипт выполнит:
1. Генерацию 7 дней поминутной телеметрии (10 080 точек на канал).
2. Калибровку норм и автоматическую классификацию каналов (`CYCLIC`, `WORKING_HOURS`, `BASE_24_7`).
3. Потоковый мониторинг 8-го дня с детекцией 3-х целевых инцидентов.
4. Вывод сводной таблицы статусов в консоль.
5. Создание интерактивного файла `dashboard.html`.

### 2. Запуск тестов:
```bash
python3 -m unittest discover -s tests -p "test_*.py" -v
```

## 3 ключевых триггера аномалий

1. **Завышенная ночная база (Триггер 1) $\rightarrow$ забытый прибор:**
   - Анализ в тихие ночные часы (23:00 – 07:00).
   - Превышение ночной медианы на $\ge 40\%$ с окном устойчивости 15 минут (дебаунсинг).
   - *Шаблон:* «Канал {name} (№{id}): ночное потребление ({power} кВт) превышает норму ({norm} кВт) на {pct}%. Возможно, забыт включённым прибор.»

2. **Нарушение цикличности (Триггер 2) $\rightarrow$ подозрение на поломку:**
   - Для каналов типа `CYCLIC` (витрины, холодильные компрессоры).
   - Автоматический расчет нормального времени работы ($T_{on}$) и отдыха ($T_{off}$).
   - Срабатывает, если компрессор работает без остановки дольше рассчитанного порога (например, $> 53$ минут вместо обычных 24 минут).
   - *Шаблон:* «Канал {name} (№{id}): работает без остановки уже {dur}, обычно отключается каждые {cycle} мин. Подозрение на поломку или негерметичность.»

3. **Отклонение в рабочие часы (Триггер 3) $\rightarrow$ нештатный режим / перегрузка:**
   - Анализ в рабочие часы (07:00 – 23:00).
   - Устойчивое превышение дневного коридора ($\text{медиана} + 3\sigma$) в течение $\ge 10$ минут.
   - *Шаблон:* «Канал {name} (№{id}): потребление в рабочие часы ({power} кВт) превышает норму ({norm} кВт) на {pct}%. Нештатный режим или перегрузка оборудования.»

## Веб-дашборд (2 экрана)

Откройте `dashboard.html` в браузере. Дашборд работает полностью автономно (офлайн) и содержит:

- **Экран 1 (Сводная таблица):**
  - Статусы каналов: 🟢 Норма / 🔴 Отклонение с бейджами.
  - Текущие физические показатели: активная мощность (кВт), ток (А), напряжение (В).
  - Нормативные границы: [мин — медиана — макс].
  - Текстовый вывод последней детекции по шаблону.
  - Интерактивный переключатель срезов времени:
    - *🔴 03:30 Ночной инцидент (холодильник + забытый прибор)*;
    - *🔴 12:30 Дневной инцидент (перегрузка кофемашины)*;
    - *🟢 23:59 Итоги суток (нормализация)*.

- **Экран 2 (График энергопотребления):**
  - Факт расхода (сплошная линия).
  - Закрашенный полупрозрачный коридор нормы ($\text{медиана} \pm 1\sigma$).
  - Подсвеченные красные маркеры сработавших аномалий.
  - Всплывающие тултипы при наведении на маркер (тип, время начала, длительность и текст предупреждения).
